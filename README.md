# Exemplo-2-TODO
Essa seria a segunda parte do gerenciador de tarefas simples, com um pouco mais de interação permitindo editar, excluir e um botão de status aonde o usuário pode informar se a tarefa está concluída ou não.
COMO USAR:
1° passo: copie e cole o link em seu navegador -->    https://dihogoferreira.github.io/Exemplo-2-TODO/
2° passo: adicione a tarefa no campo em branco pressione OU click no botão (ADICIONAR TAREFA).
3° passo: se o nome da tarefa estiver errado pressione ou click no botão (EDITAR), logo em seguida aparecerá uma caixa de texto para a correção da informação após atualizada pressione ou click em OK para concluir a atualização da informação.
4° passo: após concluir a tarefa, pressione ou click no botão (PENDENTE) para que o status mude para (CONCLUÍDO).
5º passo: eu recomendo que conclua todo o roteiro de tarefas, para que comece a exclusão da lista.
